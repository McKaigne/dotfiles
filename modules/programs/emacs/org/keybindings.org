* Reading the keys

Meow uses normal mode for editing commands, insert mode for typing, and motion
mode for tool buffers. In normal mode, ~i~ starts inserting before point, ~a~
after point, and ~Esc~ returns to normal mode.

The text editing layout is US QWERTY (~h/j/k/l~ for left/down/up/right).
Notes and journals are stored under ~~/Areas/Org/~.

* The Space menu

~SPC~ shows every key with its name. Menus marked … stay open like
Centaur Emacs's hydras: press their keys again and again; ~q~, ~C-g~ or any
other key closes them.

|---------------+----------------------------------------------------------|
| ~SPC SPC~     | Find a file in this project                              |

* Centaur Emacs's keys

These work as they do in Centaur Emacs, in every Meow state.

| Key                 | Action                                           |
|---------------------+--------------------------------------------------|
| ~F2~                | Dashboard (~q~ closes it)                         |
| ~F5~ · ~M-F5~       | Start debugging · debug menu                     |
| ~C-F5~ / ~C-c x~    | Run this file (quickrun)                         |
| ~F7~ · ~M-F7~       | Centered writing · reading mode                  |
| ~F8~ · ~M-0~        | File tree · focus it                             |
| ~C-`~ · ~F9~        | Drop-down terminal (ghostel) · in a window       |
| ~F12~ · ~C-F12~     | Agent shell · gptel                              |
| ~M-i~ · ~M-n~ / ~M-p~ | Highlight symbol · next / previous occurrence  |
| ~C-=~               | Expand the selection                             |
| ~C-;~               | Edit all occurrences (iedit)                     |
| ~C->~ / ~C-<~       | Add a cursor at the next / previous match        |
| ~C-:~ · ~C-'~       | Jump to a character (avy)                        |
| ~M-o~               | Open a link by letter                            |
| ~C-,~               | Jump to the last change                          |
| ~C-.~ · ~s-.~       | Symbols in this file · act on what's here        |
| ~M-.~               | Do the obvious thing here (embark)               |
| ~M-s ...~           | Search: ~l~ lines, ~r~ ripgrep, ~g~ grep, ~d~ find |
| ~M-g ...~           | Go to: ~g~ line, ~i~ symbol, ~e~ error, ~f~ issue |
| ~M-y~ · ~C-c k~     | Paste from history · kill ring                   |
| ~TAB~               | Indent, then complete                            |
| ~M-m~ (in popup)    | Move the completion list to the minibuffer       |
| ~M-.~ (in a picker) | Preview the candidate                            |
| ~C-c C-o~ (picker)  | Export the list to an editable buffer            |
| ~C-c C-,~ (Org)     | Insert a block template                          |
| ~C-x u~             | Undo tree                                        |
| ~C-h b~             | Every key binding, searchable                    |

In a file prompt, ~C-x C-d~ jumps to a recent or project directory. Search
results exported with ~C-c C-o~ are editable and save across files.
Errors show inline next to the code; changed lines get a git bar in the fringe.
