* How keys work

Meow, as its docs set it up. *Normal* state edits (selection first, then an
action), *insert* types (~i~ / ~a~, back with ~Esc~), *motion* is for tool
buffers (dired, Magit, help: ~j~ / ~k~ move, everything else is theirs).

~SPC~ opens the *keypad*: Emacs's own keys without holding Ctrl.

| Type        | Means       | Example                       |
|-------------+-------------+-------------------------------|
| ~SPC x …~   | ~C-x …~     | ~SPC x s~ save (~C-x C-s~)    |
| ~SPC c …~   | ~C-c …~     | ~SPC c c~ in Org (~C-c C-c~)  |
| ~SPC h …~   | ~C-h …~     | ~SPC h f~ describe function   |
| ~SPC m …~   | ~M-…~       | ~SPC m x~ run a command (M-x) |
| ~SPC g …~   | ~C-M-…~     | ~SPC g x~ eval defun          |
| ~SPC <letter>~ | ~C-c <letter>~ | the leader keys below    |

After ~x~ / ~c~ / ~m~ / ~g~ the next keys get Ctrl; press ~SPC~ first for a
plain key (~SPC x SPC p~ is ~C-x p~). An undefined ~C-x C-k~ falls back to
~C-x k~, so the short form usually works.

* Edit many places at once (beacon)

1. Select the area, press ~G~ (grab).
2. Inside it, a motion marks every match: ~w~ every word, ~v~ every search
   match, ~f~ every character, ~x~ every line.
3. ~c~ / ~i~ / ~a~ and type: leaving insert applies it everywhere. Or ~F3~,
   do anything, ~F4~ to replay it at every cursor.

* Terminal

~SPC t~ opens vterm in the bottom panel. It starts in normal state like any
buffer: ~i~ to type into the shell, ~Esc~ back to normal.

* Language support

Language servers start on their own for Nix, C/C++, Python, shell, JSON,
YAML, CSS/HTML, Lua, TOML and Markdown. Tree-sitter highlighting is used
wherever a grammar exists. Notes and journals live in ~~/Areas/Org/~.
