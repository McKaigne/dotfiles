* Reading the keys

Meow uses normal mode for editing commands, insert mode for typing, and motion
mode for tool buffers. In normal mode, ~i~ starts inserting before point, ~a~
after point, and ~Esc~ returns to normal mode.

The text editing layout is US QWERTY (~h/j/k/l~ for left/down/up/right).
Notes and journals are stored under ~~/Areas/Org/~.

* Editing with Meow (US QWERTY)

| Key                   | Action                                      |
|-----------------------+---------------------------------------------|
| ~h/j/k/l~             | Move left / down / up / right               |
| ~H/J/K/L~             | Extend selection left / down / up / right   |
| ~b/e~                 | Back / next word                            |
| ~w/W~                 | Mark word / symbol                          |
| ~x/X~                 | Select line / goto line                     |
| ~o/O~                 | Select block / to block                     |
| ~i/a~                 | Insert / append                             |
| ~I/A~                 | Open line above / below                     |
| ~c/s/d~               | Change / kill / delete                      |
| ~y/p~                 | Save (copy) / yank (paste)                  |
| ~u/U~                 | Undo / undo in selection                    |
| ~g/G~                 | Cancel selection / grab                     |
| ~,/./[/]~             | Inner / bounds / beginning / end of thing   |
| ~SPC h t~             | Interactive Meow tutorial                   |

* Added since

| Key           | Action                                          |
|---------------+-------------------------------------------------|
| ~SPC j / J~   | Jump to any visible spot · to a line (avy)       |
| ~SPC a~       | Act on what's here (embark) · also ~C-.~         |
| ~SPC u~       | Undo tree (vundo)                               |
| ~SPC o t / T~ | Terminal (vterm) · eshell                        |
| ~SPC b i~     | Buffer list (ibuffer)                           |
| ~SPC s o / O~ | Highlight symbol everywhere · clear highlights   |
| ~SPC s c~     | Jump to the last change                         |
| ~SPC c o~     | Organize imports · ~c i~ implementation · ~c t~ type |
| ~SPC c n / p~ | Next / previous issue                           |
| ~SPC c s~     | Insert a snippet · ~SPC c x~ run this file       |
| ~SPC g t~     | File history (time machine) · ~g o~ open on remote |
| ~SPC g T~     | Project TODOs                                   |
| ~SPC p C~     | Recompile                                       |
| ~SPC w t~     | Hide / show side panels                         |
| ~SPC w u / r~ | Undo / redo window layout                       |
| ~SPC w a~     | Pick a pane by letter                           |
| ~SPC w p / P~ | Toggle / cycle popups (help, compile, messages) |
| ~SPC t i~     | Indent guides · ~t c~ colour codes · ~t o~ centered writing |
| ~SPC f S~     | Edit this file as root                          |
| ~C-h B~       | Every key binding, searchable                   |

In a file prompt, ~C-x C-d~ jumps to a recent or project directory. Search
results exported with ~SPC a~ (embark) are editable and save across files.
Errors show inline next to the code; changed lines get a git bar in the fringe.
