#+title: Emacs · Key guide
#+startup: overview
#+options: toc:nil num:nil

*Open* ~F2~ then ~?~ · *Fold a section* ~TAB~ · *Close this pane* ~SPC w q~

* Reading the keys

Meow edits: normal state for commands, insert state for typing (~i~ before,
~a~ after), motion state in tool buffers (dashboard, dirvish, help, magit,
agenda). ~SPC ?~ shows Meow's cheatsheet (QWERTY layout).

~SPC~ starts Meow's keypad. The menus below are the leader; these keys are
the keypad's own and are not menus:

| Key         | Means                                                   |
|-------------+---------------------------------------------------------|
| ~SPC c ...~ | ~C-c ...~: the current mode's commands (Doom's ~SPC m~) |
| ~SPC x ...~ | ~C-x ...~                                               |
| ~SPC h ...~ | ~C-h ...~: help, with helpful (see below)               |
| ~SPC m ...~ | ~M-...~                                                 |
| ~SPC g ...~ | ~C-M-...~                                               |
| ~SPC 0~-~9~ | digit argument                                          |

After a keypad key, Meow tries each letter with =Ctrl= first and uses the
plain letter only when the =Ctrl= version is unbound. Put ~SPC~ before a
letter to force it plain: ~SPC h SPC f~ is ~C-h f~ (plain ~SPC h f~ is
~C-h C-f~, the FAQ), ~SPC c SPC ,~ is ~C-c ,~. Or use ~SPC d f/v/k~.

* Terminal (ghostel)

~SPC o t~ toggles a terminal in a new pane, one per project, opened in
the project root; it keeps running while hidden, and closing it returns to
the window you came from. ~C-u SPC o t~ starts it fresh. ~SPC o T~ opens a
terminal in the current window (with ~C-u~, in the current directory).

Opens in insert state; keys go to the program. ~Esc~ leaves insert state
(then ~i~ to type again). ~M-SPC~ opens the leader, so ~M-SPC o t~ hides the
popup from inside it. ~C-q Esc~ sends a real
Escape to the program. ~C-.~ and the pane keys (~M-j~, ~M-k~, ~M-RET~ …) stay with Emacs.

* Files (dirvish)

~SPC o p~ toggles the project sidebar, ~SPC f d~ opens any folder in this pane. ~SPC w h~ / ~SPC w l~ move into and out of the sidebar.

| Key           | Action                                       |
|---------------+----------------------------------------------|
| ~j~ ~k~       | down / up (the arrow keys too)               |
| ~l~ ~RET~     | open the folder or file in this pane         |
| ~L~ ~o~       | open in a new pane at the bottom of the stack |
| ~h~ ~Backspace~ | up a folder                                |
| ~TAB~         | fold a folder open in place                  |
| ~m~ ~u~ ~U~   | mark / unmark / unmark all                   |
| ~C~ ~R~ ~D~   | copy / rename or move / delete (to trash)    |
| ~+~           | new folder                                   |
| ~(~           | toggle details                               |
| ~g~           | refresh                                      |
| ~Esc~         | back to the previous buffer                  |
