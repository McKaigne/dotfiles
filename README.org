* 1. Dendritic & Hermetic Architecture
This workstation implements the *Pure Dendritic Flake-Parts Pattern* coupled with the *Hermetic Wrapping Doctrine*:

- *flake-parts + import-tree*: Every module inside =modules/= is discovered automatically via =inputs.import-tree=. There are zero centralized import lists in =flake.nix= or =configuration.nix=. Every feature module under =modules/features/<name>.nix= directly exports its NixOS module via option merging.
- *Zero Home Manager & Zero Dotfiles*: Home Manager is eliminated. No symlinks are made into =~/.config/=. Every tool is an immutable Nix derivation wrapped build-time with its configuration in the Nix store (=pkgs.writeText=, =pkgs.makeWrapper=).
- *Hermetic Store Interpolation*: Keybindings, launchers, and IPC targets reference exact =/nix/store= derivation paths, eliminating ambient =$PATH= breakage.
- *Ephemeral Project Isolation*: Heavy compilers and toolchains (C++, CMake, LLVM/GCC) are decoupled from global derivations and supplied ephemerally per-project via =devenv= and =direnv=.
- *Portability*: Primary CLI and GUI packages can be run directly on any Linux distribution:
  #+begin_src nu
  nix run github:McKaigne/dotfiles#helix
  nix run github:McKaigne/dotfiles#zed
  nix run github:McKaigne/dotfiles#ghostty
  nix run github:McKaigne/dotfiles#tmux
  #+end_src

* 3. Key Conventions & Philosophy
1. *Ergonomics First, Mnemonics Second*: Two-key chords on resting fingers and sequential modal taps (=Space= \to =key=) supersede simultaneous multi-finger claw chords.
2. *The "No-Gaps" Modifier Rule*: Modifiers on the home row are physically adjacent:
   $$\text{Pinky (Alt)} \longleftrightarrow \text{Ring (Ctrl)} \longleftrightarrow \text{Middle (Gui)} \longleftrightarrow \text{Index (Shift)}$$
   - *Forbidden Combinations*: Any chord spanning non-adjacent fingers is banned:
     #+begin_quote
     =Alt + Shift=, =Ctrl + Shift=, =Gui + Alt=, =Alt + Ctrl + Shift=, and =Alt + Gui + Shift= are never used.
     #+end_quote
   - *Valid Combinations*: Single modifiers or physically adjacent pairs (=Gui + Shift=, =Gui + Ctrl=, =Ctrl + Alt=).
3. *The Gui Partition*: =Gui= (=Mod= / Super) is *strictly reserved for system utilities* (Niri compositor and Noctalia shell). No code editor or terminal may bind =Gui=.
4. *User Parameterization*: Always reference =config.mainUser= (declared in =modules/system/user.nix=). Never hardcode usernames.
5. *Nushell Exclusivity*: The login shell is Nushell. Documentation and scripts must use Nushell syntax (=save --force=, =;= chaining, =$env.VAR=).
6. *Setuid Precedence*: In =env.nu=, =/run/wrappers/bin= is strictly ahead of =/run/current-system/sw/bin= to preserve =sudo=.

* 4. Noctalia Theming Exception
The only mutable files permitted in =~/.config/= are live theme palettes generated dynamically by the Noctalia shell when switching wallpapers:
- =~/.config/niri/noctalia.kdl= \to Dynamic Niri focus ring palette
- =~/.config/fuzzel/themes/noctalia= \to Dynamic Fuzzel launcher palette
- =~/.config/gtk-3.0/noctalia.css= & =4.0= \to Imported system-wide via =/etc/xdg/gtk-*/gtk.css=
- =~/.config/zed/themes/noctalia.json= \to Evaluated dynamically by Zed

** 5.5 Nushell Interactive Shell (Evil Mode)
- *Insert Mode (=>= in Cyan)*: Type commands normally. Tap =Escape= for Normal Mode.
  - =Ctrl + Space=: Fuzzy autocompletion popup
  - =Ctrl + W= (or =i + o=): Delete word backward
  - =Shift + Enter= / =Alt + Enter=: Multiline newline
- *Normal Mode (=:= in Magenta)*: Vi command line manipulation:
  - =h / l=: Move character left / right
  - =j / k=: History down / up
  - =w / b / e=: Word forward / backward / end
  - =0 / $=: Start / end of line
  - =dw / cw / ciw=: Delete / change word
  - =u / Ctrl + R=: Undo / Redo edits
  - =/=: Search command history backward
  - *=v=*: *Open command line in Helix (=hx=) to edit as a script!*

* 6. C++ Project Scaffolding & Devenv

** 6.1 Project Templates
A reproducible template lives in =~/Projects/templates/cpp=:
#+begin_example
~/Projects/templates/cpp/
├── .envrc                     # use devenv
├── devenv.nix                 # Isolated cmake, ninja, clang-tools, gdb
├── devenv.yaml                # Devenv metadata
├── CMakeLists.txt             # Modern C++20 with compile_commands export
├── src/
│   └── main.cpp               # Hello world entry point
└── .zed/
    ├── settings.json          # Points clangd to build/
    └── tasks.json             # Pre-configured CMake tasks
#+end_example

** 6.2 Zero-LSP-Error Guarantee
On entering any project directory, =devenv.nix= automatically configures CMake and symlinks =build/compile_commands.json= to the project root. Standard library headers (=<iostream>=, =<vector>=) resolve instantly with zero red squigglies.

** 6.3 Instant Project Creation
1. Inside Zed, press *Space p n*.
2. Enter the new project name in the bottom drawer (e.g. =my-app=).
3. The project is created, =direnv= is auto-trusted via =/etc/xdg/direnv/direnv.toml=, and Zed launches the new workspace ready to build (*Space c c*).

* 8. Install on New Machine
1. Boot live NixOS installer USB and mount target filesystems to =/mnt=.
2. Clone repository:
   #+begin_src nu
   git clone https://github.com/McKaigne/dotfiles.git /mnt/etc/nixos
   #+end_src
3. Update filesystem UUIDs in =modules/hosts/castor/hardware.nix=.
4. Install system:
   #+begin_src nu
   nixos-install --flake /mnt/etc/nixos#castor
   #+end_src
