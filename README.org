* Architectural Foundation & Philosophy

This repository defines an immutable, hermetically wrapped, keyboard-driven Linux workstation architecture running on *NixOS (unstable)*.

│                        ARCHITECTURAL PILLARS                           │

│ Pure Dendritic Flake-Parts        │ Hermetic Wrapping Doctrine         │
├───────────────────────────────────┼────────────────────────────────────┤
│ • Zero centralized import lists   │ • Zero Home Manager                │

** 1. Pure Dendritic Flake-Parts
- *Zero Glue in =flake.nix=*: =flake.nix= only declares inputs and calls:
  #+begin_src nix
  inputs.flake-parts.lib.mkFlake { inherit inputs; } (inputs.import-tree ./modules);
  #+end_src
  No files, configurations, or package sets may be manually imported into =flake.nix=.
- *Automatic Discovery*: Files under =modules/= are automatically discovered via =import-tree=.
- *Option Merging*: Every feature module directly exports its configuration, allowing =flake-parts= to automatically merge all definitions across the system.

** 2. The Hermetic Wrapping Doctrine
- *Home Manager is Eliminated*: No =home-manager=, no =mkOutOfStoreSymlink=, and zero dotfiles symlinked to =~/.config/=.
- *Derivations as Configuration*: Every tool is compiled at build time into an immutable Nix derivation using =pkgs.symlinkJoin= and =pkgs.makeWrapper=.
- *In-Store Flag Injection*: Configuration files are generated in the Nix store via =pkgs.writeText= and injected via flags:
  - *Helix*: =--config ${helixConfig}=
  - *Tmux*: =-f ${tmuxConf}=
  - *Foot*: =--config=${footConfig}=
  - *Nushell*: =--config ${configNu} --env-config ${envNu}=
  - *Niri*: =NIRI_CONFIG="${niriConfig}"=
  - *Fuzzel*: =--config=${fuzzelConfig}=
- *The Noctalia Theming Exception*: The *only* mutable files permitted in =~/.config/= are live theme palettes dynamically generated by the Noctalia shell when switching wallpapers:
  - =~/.config/niri/noctalia.kdl=
  - =~/.config/foot/themes/noctalia=
  - =~/.config/fuzzel/themes/noctalia=
  - =~/.config/kdeglobals= (for Qt6 / Dolphin auto-theming)
  - =~/.config/gtk-3.0/noctalia.css= & =gtk-4.0/noctalia.css=

* Deploying on a New Device (Multi-Device Guide)

All modules under =core/=, =desktop/=, =terminal/=, =editor/=, and =apps/= are *100% host-agnostic*. 

To deploy this configuration on a second machine (e.g., =rigel= or =desktop=):

1. *Generate Hardware Config on Target Machine*:
   #+begin_src sh
   nixos-generate-config --show-hardware-config > hardware.nix
   #+end_src

2. *Create a New Host Profile*:
   Create a new directory at =modules/hosts/<hostname>/=:
   - Copy the generated =hardware.nix= into =modules/hosts/<hostname>/hardware.nix=.
   - Create =modules/hosts/<hostname>/default.nix=:
     #+begin_src nix
     { self, inputs, ... }: {
       flake.nixosConfigurations.<hostname> = inputs.nixpkgs.lib.nixosSystem {
         specialArgs = { inherit inputs; };
         modules = [
           self.nixosModules.castorConfiguration # Universal system baseline
           ./hardware.nix                        # Host-specific disk & CPU drivers
         ] ++ (builtins.attrValues (builtins.removeAttrs self.nixosModules [
           "castorConfiguration"
           "castorHardware"
           "niri"
           "helium"
           "cliamp"
           "tmux"
           "kanata"
           "desktop"
           "dolphin"
           "foot"
         ]));
       };
     }
     #+end_src

3. *Build and Activate*:
   #+begin_src sh
   sudo nixos-rebuild switch --flake .#<hostname>
   #+end_src

** 3. Emacs-Style Copy Mode in Tmux

Entered via *`Prefix + c`* (or *`Alt + PageUp`*):

- *`Space`* or *`v`*: Begin selection.
- *`M-w`* or *`y`* or *`Enter`*: Copy selection directly to Wayland clipboard (=wl-copy=) and exit.
- *`C-g`* or *`Escape`* or *`q`*: Cancel / exit copy mode.
- *`M-v`* / *`C-v`*: Page Up / Page Down.
- *`C-s`* / *`/`*: Search backward / forward in scrollback history.

* The Keyboard Engine (Kanata on Lofree Flow84)

The physical keyboard engine enforces the *No-Gaps Modifier Rule*:
$$\text{Pinky (Alt)} \longleftrightarrow \text{Ring (Ctrl)} \longleftrightarrow \text{Middle (Gui)} \longleftrightarrow \text{Index (Shift)}$$

Non-adjacent modifier combinations (=Alt+Shift=, =Ctrl+Shift=) are strictly avoided.

** Home-Row Timings & Bilateral Hold
- *Index (`f` / `j` — Shift)*: =140ms= hold timeout. Zero prior-idle lockout. Instant mid-sentence capitalization.
- *Middle (`d` / `k` — Gui)*: =170ms= hold timeout.
- *Ring (`s` / `l` — Ctrl)*: =195ms= hold timeout.
- *Pinky (`a` / `;` — Alt)*: =220ms= hold timeout.
- *Bilateral Separation*: Left-hand modifiers only trigger holds on opposite-hand keys. Rolls across the same hand automatically tap as normal characters.

** Hardware Chords (`defchordsv2`)
- *`Left Shift + Right Shift`*: Toggle *Raw Layer* (disables all tap-holds for safe password entry).
- *`z + x`*: Undo (=C-z=).
- *`x + c`*: Copy (=C-ins=).
- *`c + v`*: Paste (=S-ins=).
- *`n + m`*: Tmux Prefix (=C-b=).
- *`m + ,`*: Delete word backward (=C-bspc=).

* Shell & Development Workflow

** 1. Fullstack Development via Devenv
Compilers (=gcc=, =clang=, =rustc=, =elixir=) and language servers are *never installed globally*. 
- In any repository, run =devenv init= and declare tools in =devenv.nix=.
- =envrc= (=direnv=) loads the environment buffer-locally.
- **Helix** detects language servers on =PATH= automatically.

** 2. Nushell & Starship
The interactive login shell is *Nushell*.
- *File Writing Protocol*: Always write files using raw multiline string literals in quad backticks with non-conflicting delimiters.
- *Starship Prompt*: Two-line prompt with line 1 containing Git additions (=▴=), deletions (=▿=), and line 2 dedicated to command execution. Pulls colors dynamically from Noctalia's =~/.cache/noctalia/starship-palette.toml=.

* Maintenance & Inspection Protocol

To extract all configuration files to the clipboard without binary caches or temporary databases:

#+begin_src nu
let config_files = (
    fd . /etc/nixos ~/.config -t f -H -e nix -e kdl -e toml -e conf -e ini -e json -E .git -E flake.lock -E 'net.imput.helium' -E 'google-chrome' -E 'chromium' -E dconf -E cache -E '*.log'
    | lines
)

$config_files | each { |f| bat --style=header,grid --paging=never $f } | str join "\n" | wl-copy

print $"Successfully copied ($config_files | length) core configuration files to clipboard!"
#+end_src
